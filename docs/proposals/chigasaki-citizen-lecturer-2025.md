## 講座の概要

### どんな場なのか

つくりたいものがある人が集まって、それぞれ手を動かす場です。

前半30分ほどは、その日のテーマを講師がお見せします（AIに伝わる書き方、AIでの画像生成、AIにつくらせたページの公開、Googleフォームの活用など、回ごとに異なります）。見て「こう使うのか」とわかる時間なので、その場で作業しなくても大丈夫です。

後半は各自の作業時間。見たことを自分の題材で試すもよし、前回の続きを進めるもよし、行き詰まったところを質問するもよし。決まった進度はありません。定員5名の小さな場です。

### どんなものをつくるの？

**「こんなことをやってみたい」くらいで大丈夫です。** たとえば――

- 自分の活動やお店を紹介する1枚のページをつくってみたい
- 趣味の会の参加者を募る申込フォームをつくりたい
- チラシに載せる画像をAIで生成してみたい
- 自己紹介ページを、名刺代わりに1つ持っておきたい

完成させることより、「AIってこう使うのか」と持って帰れることを大切にしています。はっきり決まっていなくても、当日その場で一緒に見つけられます。

### 講座の形式

| 項目 | 内容 |
|---|---|
| 開催場所 | 茅ヶ崎市民プラザ（または市指定の会場） |
| 開催形式 | オフラインのみ |
| 定員 | 5名 |
| 所要時間 | 2〜3時間 |
| 参加費 | 各回500円 |
| 申込方法 | Google フォーム |
| 各回の形式 | 前半：座学30分（講師のデモ）／後半：各自の作業時間 |

### 参加にあたって

- パソコン教室ではありません。操作の手取り足取りの説明はいたしません。
- ノートパソコンをご持参ください（貸出はありません）。
- 各回は独立しています。気になる回だけのご参加も、続けてのご参加も歓迎します。毎回テーマを変えて連続して開いています。
- 各回のテーマと日程は、申込フォームからご確認ください。

## メインペルソナ

### 地域でイベントを開催している個人・小規模事業者

| 項目 | 内容 |
|---|---|
| 年齢層 | 35〜55歳 |
| ITスキル | パソコンを使いこなし、Word・Googleドキュメント・Canvaは使える |
| プログラミング経験 | なし |
| AI経験 | ChatGPTなどを少し使ったことがある |
| 開催しているイベント | セミナー、講座、ワークショップ、マルシェ、サロンイベント、コミュニティイベント |
| 現在の集客方法 | Instagram、Facebook、LINE公式アカウント、口コミ、チラシ |

#### 課題

- LP（ランディングページ）が作れない
- 告知文を書くのに時間がかかる
- デザインが苦手
- 画像制作に時間がかかる
- Googleフォームをうまく使えていない
- AIを仕事でどう活用すればよいかわからない
- 外注する予算がない

#### 得たい成果

- AIを活用してイベント告知を効率化したい
- 自分でLPを作れるようになりたい
- AIで画像を作成したい
- AIでデザインを作りたい
- Googleフォームで申込受付ができるようになりたい
- QRコードで簡単に申込ページへ案内したい
- 無料ツールを活用してイベント公開まで完結したい

### サブペルソナ①：副業・個人事業を始めたばかりの人

コーチ、カウンセラー、ハンドメイド講師、ヨガ・ピラティス講師、整理収納アドバイザーなど。告知に時間をかけられず、AIを仕事に取り入れたいが、ホームページを作るほどではない层。

### サブペルソナ②：地域団体・コミュニティ運営者

PTA、NPO、商店街、市民活動団体など。予算が少なく、無料ツールだけで運営したい、誰でも更新できる仕組みを作りたい层。

## ワークショップのゴール

受講後には次のことができるようになる。

- AIを使ってイベント紹介文を作成できる
- マークダウンでLPの元となる情報を整理できる
- AIに伝わるプロンプトを作成できる
- AIでイベント画像を作成できる
- AIでLPデザインを作成できる
- Googleフォームで申込フォームを作成できる
- 回答内容に応じた分岐（ルーティング）を設定できる
- Webサイトへフォームを埋め込める
- QRコードを作成してイベントを公開できる

## 全9回カリキュラム

各回は独立しています。通しで参加しなくても問題ありません。ただし、1〜7回で「自分の題材が形になり、公開・受付まで到達する一本道」になり、8・9回は「その先を覗く発展回」となります。

| 回 | テーマ | その日わかること／持って帰るもの |
|---|---|---|
| 1 | AIに伝わる書き方 ― マークダウンで考えを渡す | AIへの指示が通りやすくなる書き方。箇条書き1枚で伝える感覚 |
| 2 | AIとの壁打ち ―「なぜ・誰に」を一緒に掘る | 自分の"つくりたい"の輪郭。曖昧でOK、言葉にする体験 |
| 3 | AIで画像をつくる | 自分の題材に使える画像1枚のイメージと、頼み方のコツ |
| 4 | Claudeのアーティファクトって何？ | 対話だけでページやツールが立ち上がる驚き。下書きの種 |
| 5 | AIにページをつくらせる ― 1枚のLPまで | 紹介ページ／告知ページのプロトタイプの作り方 |
| 6 | つくったページを世に出す ― 公開の仕組み | 「手元のもの」を「URLで見せられるもの」にする道筋 |
| 7 | Googleフォームで受け付ける | 申込・アンケートを受け取る仕組み。QRコードまで |
| 8 | コーディングエージェント入門 ― Claude Codeって何？ | "AIが手を動かす"世界の入り口。できることの地図 |
| 9 | Figma MCP入門 ― デザインとAIをつなぐ | デザインデータをAIに渡す最前線。濃い回、腕試し |

### 並びの意図

- **1〜7回**：自分の題材が形になり、公開・受付まで到達する一本道。ここだけで完結感がある。
- **8〜9回**：その先を覗く発展回。難易度が跳ねるので後ろに寄せ、「もっと知りたい人向け」と明示する。
- マークダウン（1回目）は記法の勉強ではなく **AI対話の土台＝伝わる書き方** として出す。初回に来た人はその日から2回目以降のAI対話が上手くなる。
- 座学は「見て理解する時間」。ハンズオンにしないので、その場で手を動かさなくてよい。手を動かすのは後半・自宅・翌週でもいい。
